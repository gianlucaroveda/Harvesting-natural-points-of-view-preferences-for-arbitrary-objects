Harvesting natural points-of-view preferences

A framework for harvesting point-of-view preferences silently captured while users perform unrelated visual tasks.

⌖ ABSTRACT

Finding the optimal viewpoint for a 3D object is crucial for visualization, digital marketing, and shape retrieval. Because viewpoint preference is driven by subjective semantic and aesthetic biases, data-driven approaches require large datasets of user preferences. In this work, we present a framework to crowdsource this data by implicitly tracking user viewpoints during casual interaction with 3D objects. We publicly release both our collected viewpoint dataset and the configurable tool used to harvest it.
